# Basic VLAN Configuration

Simulasi konfigurasi VLAN dasar menggunakan Cisco Packet Tracer.

## Deskripsi
Project ini menggunakan:
- 1 Router
- 1 Switch
- 3 PC

Setiap PC ditempatkan pada VLAN yang berbeda untuk memisahkan jaringan.

## VLAN
- VLAN 11 : Guru
- VLAN 12 : Siswa
- VLAN 13 : TU

## Konfigurasi
### Router
- Sub Interface
- Encapsulation dot1Q
- Inter VLAN Routing

### Switch
- VLAN Configuration
- Trunk Port
- Access Port

### PC
- Static IP Address

## Implementasi
VLAN digunakan untuk memisahkan jaringan berdasarkan divisi atau kebutuhan tertentu agar jaringan lebih aman dan terorganisir.

## Kelebihan
- Broadcast domain lebih kecil
- Keamanan jaringan lebih baik
- Manajemen jaringan lebih mudah
